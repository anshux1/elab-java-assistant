# eLab Java Assistant · Extension

**Solve** inserts a generated Java solution for review. **Copy** exports the problem and grading requirements as Markdown.

Runs only on [SRM eLab](https://dld.srmist.edu.in/fshelab/). Chrome/Edge 114+.

[Installation guide](../INSTALLATION.md) · [Download ZIP](https://github.com/anshux1/elab-java-assistant/raw/refs/heads/main/elab-java-assistant.zip)

The extension receives progress through a single streamed request, preserves edits made while solving, and inserts only the final answer. Closing the page cancels the request. It never triggers Run, Evaluate, Save, or Reset.
